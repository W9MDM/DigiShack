# QSL card artwork

Put your card artwork here and point `qsl.card.baseImage` (Settings → QSL) at it.

Nothing in this directory is committed — artwork is the operator's own asset and a
full-resolution card runs to tens of megabytes. Only this README is tracked.

The renderer composites the QSO table onto whatever it is given, so the base image
needs no reserved space or placeholder text. A 3:2 landscape image matches the
traditional card proportion; anything else works but the table is positioned as a
fraction of the image, so extreme aspect ratios will look odd.
